# Assumptions register

Assumptions are stored in:

```text
data/config/assumptions.json
data/config/scenario-parameters.json
```

## Editable parameters

- Low realization rate
- Timing factor
- Delay months
- Annual commissioning cap
- High uplift GW
- High multiplier
- PUE

## Default Low realization curve

| Year | Low realization |
|---|---:|
| 2026f | 25% |
| 2027f | 35% |
| 2028f | 45% |
| 2029f | 55% |
| 2030f | 65% |

## Notes

Assumptions can be changed from the dashboard. Changes are stored in browser state during the session.
